      ℹ️ What's happening here?

        an id, the original text, metadata (page, section…) and the vector. Below are the real rows read back from the database.

      ℹ️ What's happening here?

      ℹ️ What's happening here?
      
Your question is embedded with the same model, then compared with every chunk using cosine similarity
        (1 = same meaning, 0 = unrelated). The top-k chunks are pasted into the prompt — that is the "Augmented" in Retrieval-Augmented Generation.
        Tip: switch to recursive / 500 and search the wedding question to see a section heading get cut off from its text.
